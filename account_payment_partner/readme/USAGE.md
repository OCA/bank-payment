You are able to add a payment mode directly on a partner.

This payment mode is automatically associated to the invoice related to
the partner. This default value could be changed in a draft invoice.

On customer invoices, a payment mode with a fixed link to a bank
journal sets the invoice's 'Recipient Bank' to the bank account of that
journal, so the customer knows where to pay (e.g. by credit transfer).

When you create a payment order, only invoices related to chosen payment
mode are displayed.

Invoices without any payment mode are displayed too.
